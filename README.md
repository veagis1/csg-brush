# CSG Brush 0.6.2

For Unity 6000.6 or later. In **Window → Package Manager**, choose **Install package from git URL** and paste the URL below.

```text
https://github.com/veagis1/csg-brush.git
```

Append `#v0.6.2` to pin the release. To develop the package, clone this repository and open [Development~/Sandbox](Development~/Sandbox) in Unity.
