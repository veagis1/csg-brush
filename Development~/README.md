# Разработка CSG Brush

Откройте `Sandbox` в Unity 6000.6.8f1. Стенд использует пакет из корня этого клона, URP и Input System. Пакет устанавливается по Git URL форка. Unity пропускает каталог `Development~` при импорте ресурсов пакета.

[Карта базы знаний](Knowledge/Карта.md) · [Правила проекта](../AGENTS.md) · [Проверки Unity](Knowledge/Системы/Автоматизация-Unity.md)

Из корня репозитория запустите `powershell -NoProfile -ExecutionPolicy Bypass -File Development~/Tools/Check-Knowledge.ps1` для проверки базы.

Инструменты разработки используют Caveman 4.1.0. [Лицензия](Tools/Caveman/LICENSE) · [Уведомления поставщика](Tools/Caveman/NOTICE). Лицензия стороннего примера Chisel хранится вместе с его сценой.
