# Язык интерфейса CSG Brush

Откройте **Edit → Project Settings → CSG Brush**. В первой строке **Язык интерфейса / Language** выберите **English** или **Русский**. При отсутствии сохранённого выбора пакет запускается на английском. Ранее выбранный русский продолжает действовать после обновления. Выбор применяется в открытом редакторе и хранится у пользователя на компьютере в `EditorPrefs` под ключом `digital.dream.csgbrush.editor.language`. Значения — `ru` и `en`. Одна настройка действует в проектах этого пользователя, где установлен пакет.

На выбранный язык переключаются [панель сцены](Панель-и-инструменты-сцены.md), выпадающие списки, собственные инспекторы, подсказки, настройки и подписи размеров. Например, шаг `0,125 м` отображается как `0.125 m`. Ввод размеров принимает запятую и точку в обоих режимах. Значения брашей хранятся в метрах.

В английском режиме список **Create** строится из тех же 13 команд, что **Создать**. Для добавления инструмента зарегистрируйте его обработчик с путём под `BrushCommandMenu.CreateRoot`, задайте приоритет и добавьте перевод названия. Панель берёт обработчик, порядок и условие доступности из регистрации команды. Отображаемый текст переводится при открытии списка. Создание из GameObject и интерактивное построение из панели сохраняют собственные обработчики.

Русские строки служат ключами словаря `BrushEnglish`. Перевод подбирается перед отрисовкой, форматируемые сообщения используют одинаковые позиционные параметры для обоих языков. Для новой строки добавьте английский вариант в словарь. При отсутствии перевода интерфейс покажет исходный текст.

Заголовок компонента **Brush** и его путь в **Add Component** остаются английскими при обоих языках. Это же правило действует для названий инструментов и контекстов Unity, записей Shortcut Manager и четырёх команд порядка брашей — **To First**, **To Last**, **Move Up**, **Move Down**. Существующие пользовательские сочетания привязаны к прежним идентификаторам команд. Поля и кнопки внутри Inspector следуют выбранному языку.

Нативные меню пакета с обработчиками без параметров переключает `BrushCommandMenu`. Для этого в Unity 6000.6 используются внутренние методы `Menu.AddMenuItem` и `Menu.RemoveMenuItem`. Если версия Unity не предоставляет эти методы, панель продолжает строить собственный переведённый список.

Переключение языка и совместимость меню проверены на исходной [ветке перевода](../Проверки/Язык-интерфейса.md). Текущие названия Unity и поведение без сохранённого выбора описаны в [проверке английских названий](../Проверки/Круговая-сетка-и-названия-Unity.md).
