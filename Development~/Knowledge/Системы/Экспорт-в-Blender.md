# Экспорт группы в Blender

Выберите в Hierarchy группу брашей и нажмите **Сохранить в Blender…** в Inspector. Укажите путь с расширением `.blend`. При повторном сохранении можно перезаписать файл или выбрать новое имя. Группа хранит последний путь. Файл в `Assets` импортируется в Unity.

Экспорт записывает итоговые меши группы с учётом вырезов. Начало координат находится в группе, размеры указаны в метрах, верх в Blender направлен по оси Z. Файл содержит нормали, UV материала и имеющиеся UV карт освещения. Для URP Lit и Standard экспорт создаёт материалы Principled BSDF с поддерживаемыми текстурами. Параметры брашей, WCS, планы и связи вычитания хранятся в Unity. Последующие правки меша в Blender не изменяют исходные браши.

Требуется Blender 3.6 или новее. Редактор запускает отдельный фоновый процесс. При необходимости укажите исполняемый файл в **Настройки проекта → CSG Brush → Blender**. Параметр **Упаковывать текстуры** включает изображения в файл. При выключенном параметре получателю нужны файлы изображений по доступным путям.
