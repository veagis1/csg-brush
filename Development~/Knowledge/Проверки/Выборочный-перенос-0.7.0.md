# Выборочный перенос из 0.7.0

За основу взят форк 0.6.2 (`da39d959`). Из авторского выпуска 0.7.0 (`15529d88`) адаптированы исправления полой геометрии и зависания при дальней точке, экспорт Blender, сеансовые параметры панели и меню правого клика. [Изменения автора](https://github.com/jaroslavstehlik/csg-brush/compare/v0.6.0...v0.7.0).

## Что проверяется

- При переносе полого браша лучи снаружи и из полости должны определить владельца. Проверяются материалы и флаги статичности для добавления и вычитания, сборка по ячейкам, повторное использование кэша и загрузка старого результата.
- Сплайн с точкой в 100 км должен собираться целиком. Возвращение точки восстанавливает обычную сборку по ячейкам. Экранная проверка охватывает косые лучи, перспективную и ортографическую камеры.
- Меню правого клика использует команды текущего контекста. Сеансовая правка инструментов сохраняет сериализованные параметры проекта. Смена формы возвращает настройки формы, сохраняя ручной выбор операции форка.
- Blender должен открыть экспорт с верными размерами в метрах, осями, нормалями, UV, материалами и текстурами. Проверяются упаковка изображений, внешние ссылки и повторная запись.

## Среда

Windows, Unity 6000.6.8f1, Pipeline 1.0.0, Test Framework 1.8.0, Blender 5.3.0. Исходный каталог 0.6.2 содержит 606 имён EditMode, включая три замера с атрибутом Explicit. Для сравнения каталог снят с отдельной копии исходной версии.

## Целевые проверки

Отдельно прошли 48 целевых случаев. Из них 47 относятся к шести классам ниже, ещё один проверяет чтение прежнего формата настроек. `BlenderExportTests` — 5, `BrushSessionAndMenuTests` — 8, `BrushCreationToolTransitionTests` — 23, `GeneratorPrefabTests` — 1, `HollowBrushTests` — 5, `IncrementalBuildTests` — 5.

Графический Inspector группы показал кнопку **Сохранить в Blender…**. У цилиндра панель показала стороны, полость, толщину в метрах и операции. При проверке сцены 3 Blender записал файл размером 90 371 байт. Unity импортировала его как GameObject через `ModelImporter`. Отдельный тест вызвал тот же метод сохранения, что и кнопка Inspector. После изменения ширины браша с 2 до 4 м импортированный меш обновился, GUID сохранился, в группе записался относительный путь. Ошибка следующего сохранения оставила прежнюю модель доступной. Blender также повторно открыл файлы с упакованными и внешними текстурами.

На итоговом коде в Play Mode сцены `Assets/3.unity` кадры продвинулись с 39 до 71, повторное измерение дало 56 и 57. Обнаружены два коллайдера. После Stop редактор вернулся в Edit Mode, настройка Run In Background вернулась с true к исходному false. За эту проверку не зарегистрировано ошибок или предупреждений.

## Полный прогон

Из 625 уникальных случаев EditMode прошли 622 из 622 обычных за 66,8 с и 3 из 3 явных замеров производительности за 0,77 с. Полные имена совпали с каталогом Test Runner. Включены все 606 исходных случаев 0.6.2 и все 19 новых. Падений, пропущенных и неопределённых результатов — 0. Три диагностики `BRUSH_PROBE_SCENE` проверены на `Assets/1.unity`. Отдельный каталог PlayMode пуст.

Первый прогон обнаружил несовместимость при чтении старого JSON в `LegacyUnitSettingsConvertTheirLengthsOnceAndKeepOtherValues`. Исходные имена полей сохранены в сериализуемой базе настроек. Прежний тест без правок прошёл отдельно и в полном прогоне. При настройке тестов экспорта также устранена несовместимость добавочной сцены с безымянной сценой Test Runner.

В графическом редакторе штатный построитель контекстного меню Scene View вернул семь русских команд для браша. Выполнение пунктов переключило выбор с вершин на рёбра и вернуло обычный контекст объектов при выходе. Физический щелчок правой кнопкой и системный диалог выбора имени файла не автоматизировались.

При компиляции остались четыре предупреждения CS0618 в прежних `BrushPickingTests` и `BrushScriptingTests`. Полный прогон зарегистрировал четыре предупреждения PhysX о пределе в 256 полигонов для выпуклого MeshCollider (три для `solid Piece 1`, одно для `solid Piece 2`).

Временные редакторы закрыты, блокировки сняты. Фоновая проверка использовала отдельные процессы Blender. После испытаний восстановлены настройки Sandbox и исходные GUID трёх корневых .meta, которые графический Editor переписал при конфликте с локальной копией Chisel. Временные сцены, файлы экспорта и копия исходного стенда удалены.

## Повторная проверка выпуска 0.7.1

27 ноября в отдельной фоновой копии Sandbox Unity 6000.6.8f1 подтвердила пакет 0.7.1. Компиляция завершилась с четырьмя прежними предупреждениями CS0618. В EditMode прошли все 625 случаев каталога по полным именам, включая 622 обычных за 63,28 с и три явных замера за 0,70 с. Падений и пропусков — 0. Проверены пять случаев экспорта в Blender 5.3.0 и три диагностики на `Assets/1.unity`.

PhysX выдал четыре предупреждения о пределе 256 полигонов выпуклой оболочки и одно о расстоянии между вершинами треугольника свыше 500 м. Каталог отдельных PlayMode-тестов пуст. При запуске сцены `Assets/3.unity` кадры продвинулись со 150 до 530, обнаружены два коллайдера. После Stop редактор вернулся в Edit Mode и восстановил исходное значение `runInBackground=false`.
