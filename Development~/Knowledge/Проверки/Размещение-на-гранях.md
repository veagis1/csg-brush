# Размещение на гранях

Проверка выполнена на ветке `codex/surface-placement-and-face-snapping`. Среда — отдельная временная копия Sandbox и пакета, Windows 11, Unity 6000.6.8f1, Unity CLI 1.0.1 и Pipeline 1.0.0. Компиляция и тесты шли в `batchmode`. Для проверки Inspector и Scene View запускался графический Editor с вводом через `SceneView.SendEvent`.

## Целевые проверки

На итоговых исходниках прошли 136 из 136 случаев. Имена каждого случая совпали с каталогом Pipeline.

| Набор | Прошло |
| --- | ---: |
| `SurfacePlacementPoseTests` | 22/22 |
| `PlacementSurfaceTests` | 9/9 |
| `SceneClickTests` | 22/22 |
| `BrushCreationWorkflowTests` | 16/16 |
| `BrushDrawTests` | 20/20 |
| `ObjectEdgePlacementTests` | 26/26 |
| `BrushSnapTests` | 21/21 |

События Scene View подтвердили выбор центра видимой грани инструментом WCS, центр и четыре направляющие в режиме «Переместить к», а также подтверждение и отмену размещения цилиндра на вертикальной грани. Расчёт опоры проверен на брашах, сгенерированной геометрии и дочерних мешах под повёрнутыми, неравномерно масштабированными и зеркальными родителями. Проверки рисования покрывают размеры основания, высоту и Ctrl-привязку.

- Оба случая `WorldFloorIntersectionHasExactlyZeroHeight` подтвердили точное Y = 0 м при пересечении мировой плоскости сверху и снизу. Y осталось ровно 0 м без округления и с шагом сетки 0,125 м. `AGridPlaneAboveTheWorldFloorKeepsItsHeight` подтвердил сохранение смещённой рабочей плоскости на Y = 0,75 м.
- Оба случая `SphereStaysRoundWhenConfirmedAtTheRadiusRelease` создали ровно один сферический браш с равными размерами по X, Y и Z. В одном случае радиус и подтверждение разделяло событие `MouseMove` на той же точке. Во втором подтверждение поступило сразу.

В промежуточном прогоне выявились два сбоя. Ввод до доставки `Selection.selectionChanged` оставлял режим с пустым источником и передавал первый щелчок выделению Unity. У дочернего меша под зеркальным родителем зазор между опорой и гранью составлял 0,616527 м. После синхронизации выделения при событии Scene View и согласования расчёта опоры с локальным поворотом все соответствующие тесты прошли.

## Scene View и Inspector

- Команда «Переместить на» из меню включила штатный Move. Shift-перетаскивание браша обновило предпросмотр с координат (3,55999; 2; 0,48) м до (2,47999; 2; 0,42) м. Первое положение одновременно прочитано из `TransformInspector`. В Inspector сохранялись `TransformInspector` и `BrushEditor` исходного браша. После отпускания локальная +Y совпала с нормалью поверхности. Undo вернул исходную позу, Redo восстановил подтверждённую.
- Щелчок по центру горизонтальной грани поставил браш в (3; 2; 0) м и открыл направляющие. При смещении с Ctrl получена позиция (3,5; 2; 0) м. Esc вернул исходную позицию и поворот, выделение сохранилось.
- Кнопка ↻ перенесла отступ 0,48998 м с направляющей +X на −Z. Щелчок по слайдеру установил 0,753 м. Щелчок «Применить» зафиксировал (3; 2; −0,753) м. Undo восстановил исходную позицию.
- Первый щелчок по центру вертикальной грани сразу после смены выделения поставил цилиндр в (4; 3; 1) м с локальной +Y вдоль мировой −Z. После запоздалого `Selection.selectionChanged` открытая направляющая и выделение цилиндра сохранились.

Графическая проверка завершилась с 0 ошибок и 0 предупреждений в консоли.

## Полный прогон и Play Mode

Каталог содержал 560 случаев EditMode и 0 случаев PlayMode. За 64,02 с прошли все 557 применимых случаев EditMode. Полные имена совпали с каталогом. Test Runner зарегистрировал 0 падений, 0 пропусков и 0 неопределённых результатов. Из обычного прогона исключены три замера с атрибутом `Explicit` из `BrushManagementProbe`, включая два параметризованных случая. Выполнены все три проверки `BRUSH_PROBE_SCENE` на временной сцене с двумя добавляющими брашами и одним вычитающим.

В консоли полного прогона было 0 ошибок и 4 предупреждения Unity о частичной выпуклой оболочке MeshCollider при лимите 256 полигонов (`solid Piece 1` трижды, `solid Piece 2` один раз).

В отдельной проверке Play Mode сцена с полом и префабом «Игрок» продвинулась с кадра 163 до кадра 573. Дополнительное серверное ожидание зафиксировало изменение номера кадра с 359 до 377. В сцене был один активный CharacterController. Настройка Run In Background имела значение false до запуска, true во время Play Mode и вернулась к false после Stop. Консоль при выходе из Play Mode показала 0 ошибок и 0 предупреждений.

При раннем повторе тесты остановились на `SaveModifiedSceneTask` после выхода из Play Mode с сообщением `This should not be called in batch mode.` Повтор из чистой сцены в свежем временном Editor прошёл полностью. Контрольные сцены открывались только в копии Sandbox.
