# Размещение на гранях

## Сцена 3 — высота нового браша на полу, 27 ноября

В контрольном коммите `3593e75d` верхняя грань блока в сцене `Assets/3.unity` проходит через Y = 0 м. У 12 вершин выходного меша высота равна ровно 0 м. Наклонный луч из (−18,87; 60,456; −112,77) м с направлением (0,17; −1; 0,11) вернул точку на Y = −0,000002686666 м. При построении жестами Scene View начало блока, цилиндра и сферы поместилось на Y = −0,000000715255737 м в Transform Inspector и в сериализованном поле `m_LocalPosition.y`.

Для собранной грани инструмент вычисляет точку по вершинам выбранного треугольника. Для авторской грани до сборки он проецирует точку на плоскость полигона. При установке начала WCS новый браш получает мировые координаты первой точки построения.

В Unity 6000.6.8f1 десять наклонных лучей по этой грани вернули ровно Y = 0 м. В Scene View жестами создавали блок, клин, цилиндр, конус, сферу, прямую, изогнутую и винтовую лестницы, арку, дверь и окно.

Собственные параметры формы сохраняются. В контрольной сцене нижняя точка окна лежала на 0,9 м, нижняя точка винтовой лестницы — на 0,15 м. При промежуточной проверке часть вершин полукруглой арки уходила под плоскость на 0,000000238419 м из-за округления синуса на конце дуги. Для угла 180° концы диаметра теперь заданы точно, для частичной дуги концы вычисляются по заданному углу. Исходную сцену закрыли без сохранения проверочных объектов.

При свободном построении сплошной прямой лестницы высотой 3,249995 м округление координат общей вершины смещало основание на −0,000002503395 м. При объединении вершин теперь округляется только ключ поиска. Меш хранит исходные координаты.

На итоговой версии проверены 44 варианта построения: все 11 форм при четырёх сочетаниях сетки и привязки. Во всех вариантах координата Y в Transform Inspector и в сериализованном Transform равна ровно 0 м. Для девяти форм с опорой у самого пола нижние вершины лежат ровно на 0 м, включая прямую лестницу произвольной высоты и по четыре вершины каждой опоры полукруглой арки. У окна и винтовой лестницы сохранились указанные выше отступы. В отдельной копии сцены новый блок записан в YAML как `m_LocalPosition: {x: -9.25, y: 0, z: -106.125}`. После повторного открытия его мировая и локальная высота равны 0 м.

В Windows на Unity 6000.6.8f1, Pipeline 1.0.0 в batchmode прошли 169 из 169 целевых тестов. Полный прогон прошёл 603 из 603 за 68,99 с. Полные имена совпали с применимым набором каталога EditMode из 606 случаев. Три замера производительности с атрибутом `Explicit` не входят в обычный прогон. Все три проверки с `BRUSH_PROBE_SCENE=Assets/1.unity` выполнены. Падений, пропусков среди применимых тестов и неопределённых результатов нет. В консоли 0 ошибок и четыре предупреждения PhysX о пределе в 256 полигонов для выпуклых MeshCollider: три для `solid Piece 1`, одно для `solid Piece 2`.

В каталоге PlayMode нет тестовых случаев. В отдельном запуске Play Mode кадры продвинулись с 299 до 316, затем до 463 и 630. Был активен один CharacterController. Физический луч попал в `solid Box` на Y = 0 м. После Stop оба значения Run In Background (`Application` и `PlayerSettings`) вернулись с true к исходному false. Новых ошибок и предупреждений за время Play Mode не было.

## Сцена 2 — привязка без поворота, 27 ноября

Исходная версия — коммит `79376538`. В копии `Assets/2.unity` выбрали объект «2» и включили магнит при выключенном ⊥. При нажатии мыши его WCS переместилась из (−24,75; 4; 12,375) м в центр видимой грани объекта «1» (−17,25; 5,1875; −3) м. После отпускания ЛКМ открылась направляющая. За четыре обновления Editor пришли уведомления о перестройке иерархии, видимости и доступности выбора. Инструмент закрыл направляющую и вернул исходную позицию. Обе позиции зафиксированы в TransformInspector.

В исходной версии упали три из восьми целевых регрессионных случаев. Два случая обнаружили привязку сквозь грань при включённых и выключенных маркерах. Третий воспроизвёл потерю направляющей при изменении разрешения выбора постороннего пустого объекта.

В исправленной версии события Scene View в той же копии сцены подтвердили положение (−17,25; 5,1875; −3) м после отпускания и последующих уведомлений Unity. Направляющая оставалась активной. Смещение по ней на 2 м и второй щелчок поставили объект в (−15,25; 5,1875; −3) м. Undo вернул исходную позицию, Redo восстановил подтверждённую. На протяжении проверки были открыты TransformInspector и BrushEditor объекта «2». Координаты в Inspector совпали с Transform на каждом этапе.

Среда — отдельная копия Sandbox, Windows, Unity 6000.6.8f1, CLI 1.0.1, Pipeline 1.0.0, batchmode. Копия сцены совпала с исходной после проверки. Все 118 исходных файлов C# совпали с рабочим пакетом после нормализации переводов строк.

- Прошли 97/97 целевых случаев: `SceneClickTests` (30), `PlacementSurfaceTests` (12), `ObjectEdgePlacementTests` (26), `SurfacePlacementPoseTests` (22), `BrushSceneVisibilityTests` (7).
- `MoveToDoesNotSnapThroughTheVisibleFace` в обоих положениях кнопки маркеров выбрал переднюю грань. В исходной версии магнит выбирал вершину на 5 м дальше. `MoveToKeepsItsGuideAfterAnUnrelatedPickingChange` проверил смещение, подтверждение, Undo и Redo.
- `MoveToRestoresItsSourceWhenTheGuideTargetIsHidden` проверил отмену при скрытии самой цели. В первом прогоне ожидание позиции сразу после `SceneVisibilityManager.Hide` опережало доставку события. Проверка после следующего события Scene View прошла.
- Из 581 случая каталога EditMode прошли все 578 применимых за 66,6 с. Полные имена выполненных случаев совпали с каталогом. Пропусков и неопределённых результатов среди них было 0. Три замера `BrushManagementProbe` помечены `Explicit`. Три случая `BRUSH_PROBE_SCENE` выполнены на временной сцене. Проверка касалась инструмента Editor. В каталоге PlayMode было 0 тестов, вход в Play Mode для этой правки не выполнялся.
- При импорте локального Chisel Unity сообщила о трёх существующих конфликтах GUID. При компиляции зарегистрированы четыре предупреждения `CS0618`. В полном прогоне были четыре предупреждения PhysX о частичной выпуклой оболочке при лимите 256 полигонов: три для `solid Piece 1`, одно для `solid Piece 2`.

Дополнительный повтор в графическом Editor не дал результата. Pipeline завершил команду сообщением `The entry point's Task did not complete within the 60 s timeout`. Результаты Scene View и Inspector выше получены программно в batchmode.
