# Проверка переноса CSG Brush 0.6.0

Старое рабочее дерево сохранено в локальном ZIP. Для 861 файла проверен SHA-256 после записи. Последняя версия сцены «Сцена перед тестами» дополнительно упакована и проверена отдельным ZIP, так как при очистке её хэш отличался от первого снимка.

Чистый пакет `digital.dream.csgbrush` содержит 371 файл. Каждый файл совпал с версией 0.6.0 из локального пакета 8Circles. Сверены SHA-256 рабочей копии и Git-объекты перед коммитом. Коммит `9f64cbb2677586c2e4d9ae17034d742af6972df6` опубликован в `main`, удалённая вершина подтверждена через Git. Остальные изменения выполнены в отдельной ветке.

## Среда и исходный прогон

Изолированная копия Sandbox. Unity 6000.6.8f1 в batchmode, актуальная Unity CLI 1.0.1, Pipeline 1.0.0, Test Framework 1.8.0. Перед прогоном редактор достиг `ready`. Исходная компиляция прошла, курсор консоли записан. Пакет тестировался с `CSG_BRUSH_TESTS`.

У чистой 0.6.0 каталог содержит 372 случая EditMode и ноль отдельных случаев PlayMode. Три явных диагностических замера исключены. Из 369 запущенных 364 прошли, 2 упали, 3 пропущены.

- `BrushPlayModeTests.ATriggerBrushSendsUnitysTriggerMessagesToItsOwnObject`. `InvalidOperationException: This cannot be used during play mode, please use SceneManager.CreateScene() instead.` Ошибка в `finally`, строка 119.
- `SceneClickTests.AHoldIsLetGoOnlyAfterEveryToolHadTheRelease`. Ожидалось `0`, получен `4251`. Строка 147.
- Пропуски без сцены `BRUSH_PROBE_SCENE`. `ManifoldSpikeTests.LevelScaling`, `ManifoldSpikeTests.LevelThroughManifold`, `SceneProbeTests.ProbeSubtractCoverage`.
- Исключённые замеры. `BrushManagementProbe.MeasureBookkeepingInALargeLevel` и два случая `MeasureADragFrameInALargeGroup` с параметрами 250 и 1000.

В исходном прогоне после тестов в консоли появилась `InvalidOperationException` о выборе без поддерживаемых объектов для `CsgBrush.Editor.FloorPlanDrawTool`. Редактор завершён командой `editor quit` после тайм-аута `unity close`. PID и блокировка исходного прогона исчезли.

## Итоговый пакет

Изолированная копия итогового пакета совпала по SHA-256 для всех 385 файлов. Перекомпиляция завершилась успешно. До тестов ошибок компиляции и консоли не было.

| Проверка | Прошло | Упало | Пропущено |
| --- | ---: | ---: | ---: |
| `BrushCreationWorkflowTests` | 10 | 0 | 0 |
| `FloorPlanTests` в составе полного прогона | 45 | 0 | 0 |
| Полный применимый EditMode, 53,16 с | 374 | 2 | 3 |

Из 382 случаев каталога исключены те же три явных замера. Оба падения и три пропуска совпали с исходной 0.6.0. Десять новых случаев проверили знак глубины и ручной выбор, перемещение по локальной сетке, точный размер с Undo/Redo и адресные вычеты в меше и коллайдере. В первом целевом прогоне тест нашёл, что коллайдер ещё резался по старому порядку. Сборщик коллайдеров подключён к той же таблице целей, итоговый тест прошёл.

В Play Mode номер кадра увеличился с 337 до 640. После Stop восстановилось исходное `runInBackground=false`.

В графическом редакторе Scene View отрисовал три метки. Вызов Repaint штатного `BrushEditor` отработал. Синтетический щелчок сбросил выделение, поэтому открытие поля, ввод и подтверждение через плашку в этой проверке не подтвердились. Целевой автоматический тест проверил изменение ширины и Undo/Redo через тот же обработчик применения.

После полного прогона восстановлены URP 17.6.0, Input System 1.20.1 и префаб игрока. Настройки указывают исходный URP asset и `activeInputHandler: 1`. Манифест и lock-файл согласованы.

После восстановления изолированный Sandbox запустился в batchmode и достиг `ready`, ошибок компиляции и консоли не было. Unity подтвердила активный UniversalRenderPipelineAsset «URP стенда» и установленный Input System 1.20.1. У `PlayerInput` префаба «Игрок» найдены asset «Управление игроком» и карта `Exploration` с движением, обзором, прыжком, возвратом и управлением курсором. Повторный полный прогон с восстановленным профилем не выполнялся.
